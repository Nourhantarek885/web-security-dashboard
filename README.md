 # 🛡️ Web Security Dashboard

An interactive educational dashboard designed to help beginners understand common web security vulnerabilities and basic prevention techniques.

## 🚀 Live Demo

The project is currently available through GitHub Codespaces.

## 📌 Features

- 🔎 Search vulnerabilities
- 🎯 Filter vulnerabilities by severity
- 📊 Dynamic vulnerability statistics
- 🛡️ Severity classification
- 📚 Interactive vulnerability information
- 💻 Clean and responsive interface
- 📱 Mobile-friendly design

## 🔐 Covered Security Topics

| Vulnerability | Severity |
|---|---|
| SQL Injection | HIGH |
| Cross-Site Scripting (XSS) | HIGH |
| IDOR | HIGH |
| Authentication Issues | MEDIUM |
| Business Logic | MEDIUM |
| API Security | MEDIUM |

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🎯 Project Goal

The goal of this project is to provide a simple and interactive way for beginners to learn about common web security vulnerabilities, understand their risks, and learn basic prevention techniques.
